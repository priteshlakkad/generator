Source mode. This template is a complete HTML document (it has its own <head> / <style>), so it is edited as raw HTML. The rich-text editor cannot represent page rules, <colgroup> widths or print CSS and would strip them on save.
Sample data (JSON)

Top-level keys become {{token}} values. An array key repeats any table row marked with a matching data-repeat attribute (use the "Data Table" button in the editor toolbar to insert one).

Table columns

Columns are read from the saved template — every table marked with data-columns, whose cells carry data-col. Turning one off removes it from the PDF and re-flows the remaining widths. A request can override this per quotation by posting "hiddenColumns": ["mrp"].
